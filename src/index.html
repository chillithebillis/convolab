CONVOLAB — guia rápido

Fluxo

Arraste uma imagem ou vídeo para a tela (ou File ▸ Open). Escolha um preset, ajuste os parâmetros e deixe as iterações rodarem. Pause congela; Reset volta para a fonte; Freeze → Source transforma o resultado atual em nova fonte (empilha efeitos).

Kernel Lab

Na aba Lab, teste kernels sobre formas simples (ponto, linha, disco…) passo a passo, pinte luz com o mouse e veja o efeito de Σ, gain e overflow. Quando gostar, Send to Engine leva o kernel para o motor principal; Base → Source e Result → Source viram fonte.

Máscara

Carregue uma imagem/vídeo P&B em Mask (ou arraste segurando ⌥): o efeito só age no branco (ou no preto, em modo Invert). Ótimo com mattes do SAM/AUTOMATTE.

Modulação

Os LFOs e as bandas de áudio (level, low, mid, high) movem qualquer parâmetro. Em Modulation, adicione uma linha: fonte → parâmetro → profundidade. Os parâmetros modulados ficam azuis. No render, o áudio é analisado frame a frame (resultado idêntico ao que você vê).

Morph A/B

Guarde dois estados (A e B) e faça a transição pelo slider Morph. Ele também pode ser modulado (ex.: ramp ou LFO lento = animação de um look para outro).

MIDI

Clique MIDI Learn, clique no nome de um parâmetro e gire um knob do controlador. Repita para outros. Clear apaga os mapeamentos.

Render

ProRes 422 HQ / 4444, H.264 ou sequência PNG, com o áudio da fonte (ou do arquivo de áudio). Vídeo: processado frame a frame entre In e Out. Imagem: grava a evolução (frames definidos ou a duração do áudio). Todo render salva um .json ao lado com os parâmetros, e o PNG leva os parâmetros dentro.

Keyframes

Cada parâmetro tem um ◆. Clique para criar um key no tempo atual da timeline. Com keys, mexer no slider já grava um novo key (auto-key). ⇧clique apaga o key atual; ⌥clique apaga todos. Key all (K) grava todos os parâmetros visíveis. Eventos (reset, freeze, preset) são marcadores rosa na timeline.

Draw e Type

D desenha (pincel, borracha, linha, retângulo, elipse). O desenho pode entrar na fonte, pintar direto na simulação ou virar máscara. T move o texto selecionado arrastando no canvas. Fontes do sistema ou arquivo .ttf/.otf.
